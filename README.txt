DIRTY D'S - HOW TO USE
1. Upload this whole folder to the host (index.html must sit in the root next to assets/).
2. The 14 videos are in assets/videos/; the 16 gallery photos are in assets/images/ (names in assets/videos/README.txt).
3. Reviews: edit assets/js/reviews-data.js (paste real Google reviews; instructions inside).
4. Prices/packages are in assets/js/data.js (regenerate source if changed) - booking form still posts to FormSubmit.
5. Chatbot: assets/js/chatbot.js (rule-based; optional AI endpoint hook at top of file).
